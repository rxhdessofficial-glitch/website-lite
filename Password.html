Tutorial Lengkap Ganti Password Wi-Fi

Ikuti 6 langkah mudah di bawah ini untuk mengubah Nama Wi-Fi (SSID) & Password Router Anda.

⚠️

Syarat Utama Pengaturan

Pastikan perangkat HP atau Laptop Anda sudah terhubung / terkoneksi ke jaringan Wi-Fi NextLink sebelum membuka alamat IP router di bawah ini.

Step 1

Buka Browser & Ketik Alamat IP Router

Buka aplikasi browser (Google Chrome / Safari) di HP atau komputer Anda. Ketik angka alamat IP 192.168.100.1 di kolom pencarian atau URL bar.

Alamat IP Gateway Router: 192.168.100.1
Buka Halaman ↗
🔍 Klik untuk memperbesar
Step 2

Login ke Panel Admin Router

Setelah halaman login router terbuka, masukkan Username dan Password pada kolom yang tersedia seperti contoh gambar. Silahkan gunakan kombinasi kredensial login di bawah ini:

Opsi 1 (Utama)
User: admin
Pass: admin
Opsi 2 (Alternatif)
User: root
Pass: admin
🔍 Klik untuk memperbesar
Step 3

Pilih Opsi Fast Setting

Setelah berhasil login, perhatikan bagian pojok kanan atas layar router Anda. Klik menu FAST SETTING seperti yang ditunjukkan pada contoh gambar di bawah.

🔍 Klik untuk memperbesar
Step 4

Ubah Nama Wi-Fi (SSID) & Password Baru

Ketik Nama Wi-Fi baru (SSID) dan Password Wi-Fi sesuai keinginan Anda (BEBAS).

  • Ketentuan Password: Minimal 8 Karakter/Huruf (dapat dikombinasikan dengan angka).
  • Setelah selesai mengisi, tekan tombol NEXT.
🔍 Klik untuk memperbesar
Step 5

Lewati Pengaturan Kedua (Skip)

Pada tampilan langkah kedua ini, Anda tidak perlu mengisi apa pun. Langsung klik tombol SKIP di bagian bawah seperti contoh gambar di bawah ini.

🔍 Klik untuk memperbesar
Step 6

Selesai & Sambungkan Kembali Wi-Fi

Sebagai langkah terakhir, klik tombol RETURN TO HOME PAGE.

💡 Catatan: Setelah ini, koneksi Wi-Fi lama Anda akan terputus. Silahkan masuk ke Pengaturan Wi-Fi di HP/Laptop Anda dan sambungkan ulang menggunakan Nama Wi-Fi & Password Baru yang telah dibuat.

🔍 Klik untuk memperbesar

Kendala Saat Mengubah Password?

Jika Anda mengalami kendala seperti lupa password baru, tidak bisa login, atau koneksi terputus, jangan ragu untuk menghubungi layanan bantuan kami.
